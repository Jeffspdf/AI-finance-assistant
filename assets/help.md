# AI理财小助手 · 离线使用帮助

## 快速开始
建议先选择“演示空间”，用合成账单体验完整流程；个人数据请放在“我的账本”。两种空间独立保存。
在“交易账本”选择“导入账单”，预览确认后保存，再核对分类、跨源对账和退款。来源记录、人工决定和净额统计各有用途，不要把银行资金腿再次当作一笔消费。
快捷键：F1 打开帮助，Ctrl+N 记一笔，Ctrl+K 搜索。

## 账户与绑定
在“设置与连接 → 管理账户与绑定”添加钱包或银行卡，只保存账户名称、平台与末四位，不连接银行。
选中账户后可“编辑选中账户”“归档选中账户”“恢复选中账户”。类型不可编辑；类型选错时，归档旧账户并新建。
修改平台会让相关对账/退款关系待复核；改名和末四位不修改历史金额。使用中账户不能完全重复；恢复账户也会查重。
归档保留历史来源，但不允许新导入或新绑定。有活动绑定时先“结束选中绑定”，结束日期须早于今天。不要为归档随意改写真实绑定时间。

## 导入与分类
“导入账单”支持通用 CSV/XLSX、微信 CSV、银行模板 v1 XLSX。先声明正确账户；不确定时选“未指定账户”。归档账户不出现在新导入下拉。
新增账户后关闭账户窗口，下拉会刷新并选中新账户。导入窗口打开后切换空间，需要回到原空间或重新打开导入窗口。
选中交易后可改分类、编辑或同商户应用。收入、支出、转账各有对应分类；“记住此商户分类”只影响以后新导入的同类收支。
“删除这笔交易”需要确认，只软删除所选来源。它不再进入统计，相关对账/退款关系待复核；原始来源和审计保留。首版没有回收站，删除前请备份。

## 退款与口径
在“退款与待复核”或设置中的“退款与统计口径”管理退款。
只有独立退款流水经过人工关联后才抵扣；原消费仅显示“已退款”而没有退款流水时，无法确认净额。全额、部分、多次退款的累计金额不得超过同一消费事件。
一笔退款只能整笔关联一个原消费；覆盖多个消费的退款暂不自动拆单。同一退款的多来源先去重，只抵扣一次。
消费总额不扣退款；净支出扣除已确认退款。默认现金口径按退款发生月抵扣，也可回溯原消费月。切换会重算当前空间所有净额，不改原始账单，并记录审计。
单笔不能超退，但只有退款的月份净支出可以为负。已确认有效的关联必须先撤销，才能重新确认。

## 跨源对账
在账本“更多 → 跨来源对账”扫描候选，查看来源和证据后人工确认或拒绝；系统不会自动确认。
同一消费的微信/银行来源确认后只计一次；拆分后恢复分别计数。证据不足时补账户和绑定，不能仅凭同金额合并。
编辑、删除来源或修改账户平台后，相关决定可能待复核。先查看来源，必要时定点修复，再重新核对；修复不会自动重新确认。

## 预算
预算页面顶部只有一个月份选择器，包含过去 24 个月、当前月和未来 12 个月，也保留已导入月份。
无交易的月份可以提前设置预算；“尚无记录”不表示没有消费，表中的 0.00 只是已导入范围的汇总。零预算可以保存。
预算按净支出计算，消费总额同时保留。净支出为负时，剩余额度可能大于原预算；使用率没有正常正分母时不应当作正常占比。
可以“复制上月预算”或“按近三月均值建议”；覆盖前会确认。建议整批保存，出错时整体回滚。

## 储蓄
修改方案 A/B 月预算比较储蓄情景；它是假设计算，不是收益承诺。
“用近三个月账单估算”覆盖当前输入前会确认，取消后保留输入。历史平均净支出为负时，请明确填写非负未来预算，不假定退款持续发生。
记录目标与储蓄贡献前核对金额、日期和对应目标，账面结余不等于账户真实余额。

## AI 助手
本地支持月份、两个 YYYY-MM-DD 起止日期（含首尾）、分类和预算查询。复杂商户等条件可用自己配置的兼容模型理解；金额始终由本机代码计算。
“模型已配置”不等于连接成功。设置中测试连接，再保存启用；成功、未验证和失败状态会按同一客户端状态显示。
连接失败会区分密钥、余额、地址/模型、网络、超时、限流和格式等原因，不展示认证头或敏感返回正文。不要向别人发送 API Key。
回答先显示金额和一条本地洞察，“查看依据”中保留数据范围、假设、缺失信息、公式与来源。无记录不代表零消费；不预测未来投资收益。

## 数据与隐私
账单、来源和审计保存在本机；演示空间与个人空间隔离。归档账户和软删除来源不会物理抹除原始数据。
记住的 API Key 使用本机加密配置，和账本分开保存；是否记住由你选择。启用模型时只发送提示中说明的信息；未启用不调用接口。
不要把个人账本、配置或密钥上传到仓库或发给组员。课程示例是合成数据，不能替代真实数据验证。

## 备份恢复
先在“设置与连接 → 备份与恢复”创建备份；恢复前核对文件与预览，确认后才替换当前空间，并保留恢复前快照。
模式 5→6 只给账户表增加两列，迁移前自动备份，失败整体回滚。旧 rc.1/rc.2 和 v0.8.5 不能读取模式 6。
回退旧程序时必须恢复与旧程序兼容的模式备份，不要只覆盖安装旧 EXE。备份只读预览不会迁移原备份；恢复使用副本升级。

## 常见问题
找不到新版本：课程预发布通常需要到对应 GitHub Release 页面手动下载；旧客户端会忽略预发布。先退出旧版并备份，再安装。
出现未知发布者：安装包未签名。请核对来源和 SHA256，是否运行由你决定，不需要关闭系统安全防护。
历史写文件警告仍未归因，作为 known limitation 保留；它不代表所有正式发布门禁已经通过。未做干净虚拟机和真实用户试验。
帮助完全离线。帮助资源缺失或章节不完整时请重新安装完整程序。遇到崩溃、丢数据或金额异常，保留备份并反馈复现步骤，不要直接反复覆盖数据。
