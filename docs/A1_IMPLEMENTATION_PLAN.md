1. 五项ADR口径：Account/FundingLink、计数/代表、退款口径/里程碑、未来版本守卫与备份降级、M1a/M1b拆分；文档纳入版本控制。

## 范围控制

保留Windows交付、稳定数据目录、现有技术栈及角色。每包单独提交/验收；迁移前一致备份。无法回溯改变旧程序，降级采用对应备份。

六行用两对20/40元重复+10元退款+500元转账；120/60为待退款调整的消费。银行未指定前用限定模板。真实样本、标注者及时间预算后续补齐，不阻塞合成夹具，不凭空承诺3–5天。
