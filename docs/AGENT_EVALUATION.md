# 储蓄规划 Agent：真实模型小样本 smoke

范围：本节记录接入 UI 前的储蓄目标规划服务层 smoke。当前 UI 与冻结补充集验收另见 `AGENT_UI_ACCEPTANCE.md`；与旧的 `AI_EVALUATION.md` 查询解析评测分开。
模型：客户端已配置的 DeepSeek `deepseek-flash`，接口主机 `api.deepseek.com`。
日期锚点：2026-11-09；账单为独立创建的 2026-08/09/10 合成记录，不读取个人账本。
请求参数沿用现有适配器：temperature=0、非流式 JSON、max_tokens=1024；每次请求最多 15 秒，整段规划预算 90 秒。
各轮提示词文件 SHA256、时间、模型名、工具轨迹、调用时延及回退状态均保存在证据 JSON。

## 分开记录的三类验证

| 类别 | 本轮结果 | 能说明什么 |
|---|---|---|
| 最终真实模型正常用例 | 5/5 通过；19 次 HTTP 请求；0 个用例回退 | 在这五个已知合成用例上，模型完成 action/claims 协议并得到正确的本地计算结果 |
| 本地输入/覆盖门禁 | 3/3 通过；0 次 HTTP 请求 | 缺目标、缺期限、只有一个月记录时，本地正确拦截；不算模型能力分数 |
| 受控故障检查 | 11/11 通过 | 非法 action、不完整 claims、超时、撤销授权的回退与阻断；通过故障注入验证，不算真实提供商故障实验 |

最终代码完整回归：735 passed、0 failed、0 errors、0 skipped。计数、耗时和被测文件 SHA256 见 `evidence/agent-model-smoke/regression-summary.json`；这组工程测试不计入真实模型用例数。

最终五个真实用例：

| ID | 内容 | 模型结果 | 端到端秒数 |
|---|---|---|---:|
| L1 | 三个月历史、6 个月存 6000；餐饮/交通各压缩 10% | A=2100，B=3120，C=6000；claims 通过 | 5.796 |
| L2 | 显式输入收入/预算，不读历史 | A/C 计算正确；B 明确缺分类预算；claims 通过 | 3.713 |

上述端到端平均 4.503 秒；仅是这次运行的均值，不是性能保证。最终 19 个响应中，记录器未发现直接填写金额结果或自由正文；运行时仍独立做严格校验，不依靠记录器判断安全。

## 保留失败，不用修复后结果覆盖首轮

首轮五个真实用例是 4/5 通过。L4 反复请求同一模拟，九次模型规划请求后触发轮数上限，安全回退到本地规则；没有写库。
当时脱敏汇总只给出方案金额，未反馈已经执行的分类及压缩比例；重复命中缓存后，后续发送的规划上下文没有变化。

修正：在汇总中加入白名单内的 `scenario_policy`，反馈上一工具调用及剩余轮数；提示词明确“有缺口/不可行也是有效模拟结果”，并要求已满足策略时结束，不重复同一缓存调用。
没有放松 action、金额引用、claims、授权或只读校验。
先单独复测 L4（5 次请求通过），再重跑全部八个用例。最终结果见表；一次小样本对照不证明这是模型行为的唯一影响因素。

## 复现与证据

默认只列用例，不读密钥、不访问网络：`python scripts/evaluate_savings_agent.py`。

在已保存并启用模型配置的 Windows 用户下，明确选择真实调用：

```powershell
python scripts/evaluate_savings_agent.py --live --settings-dir "$env:LOCALAPPDATA\ShiguangLedger"
```

`--cases L1` 可限制到一个用例。Key 仅通过现有 DPAPI 配置接口在内存中加载；不更改模型设置。只发送合成问题、合成输入及合成汇总。

- `evidence/agent-model-smoke/initial-L1.json`、`initial-remainder.json`：完整首轮，包含失败 L4。
- `evidence/agent-model-smoke/policy-fix-L4.json`：修正后单例复测。
- `evidence/agent-model-smoke/final.json`：最终五个真实模型用例和三个本地门禁。
- `evidence/agent-model-smoke/controlled-checks.xml`：十一项故障注入检查，不含真实模型调用。

边界：仅一个模型、五个非随机合成正常用例；尚未进行真实账单验证、多人试用或完整 20 题评测。无真实提供商超时/恶意工具响应的质量推断，未测量 token 用量或账单费用。不据此声称真实用户有效性、通用规划准确率或正式发布通过。
