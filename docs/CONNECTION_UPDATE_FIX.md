# DeepSeek连接与更新下载修复（v0.7.3）

日期：2026-11-03。用户报告连接测试的通用失败提示，随后报告更新只能使用浏览器备用链接。

## 本机诊断

最初安装版为0.7.1，只有地址/模型，没有落盘Key；用户自行更新为0.7.2并重新保存后，加密配置可恢复。地址及deepseek-flash符合当前官方接口要求。经用户授权，仅将认证头发往api.deepseek.com：模型列表认证成功，所选模型可用；修正后的128输出token最小测试成功，约0.69秒，只发送测试消息，不发送账单。原始Key、密文、用户余额及响应正文不写入本报告或公开仓库。

本次没有直接捕获旧版生成失败时的完整底层异常，因此不声称已证明每次失败都来自超时；确认的是旧版仅20秒等待、未显式关闭当前DeepSeek默认思考模式、未请求JSON模式，且将多类异常合并成同一提示。新版针对这些已确认的兼容性和诊断缺陷修复。资料：[官方Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)、[模型说明](https://api-docs.deepseek.com/quick_start/pricing/)、[错误码](https://api-docs.deepseek.com/quick_start/error_codes/)。

GitHub公共release API实测403，X-RateLimit-Remaining=0；官方latest页200。原客户端的回退路径实际下载37,612,483字节v0.7.2安装包并通过官方SHA256，耗时约43.27秒。因此不是安装包永久不可用。旧界面只在发现更高版本时启用下载，当前版只能看见浏览器入口；API错误提示和网络容限也不足。

桌面查看工具初始化失败，本次定位基于本机配置元数据、已安装二进制版本、用户提供的错误文字及受限最小网络探测，没有读取进程内存中的密钥。

## 修复

- 仅官方api.deepseek.com增加thinking disabled与response_format json_object。通用兼容接口不发送专用选项。测试限128、其他结构化任务限1024输出token；超时60秒。
- 明确HTTP401/402/403/404/422/429/5xx、超时/DNS/证书/拒绝连接，以及空正文、截断、格式不兼容，错误不回显Key、代理地址或服务端原始正文。
- GitHub API限流、5xx或网络错误均可通过本项目官方latest页确认版本；发布页跳转严格限制仓库和正式版本。仍使用官方校验清单；不绕过TLS/校验，不使用第三方镜像或用户GitHub凭据。
- 同版本也允许应用内下载，标明API受限后仍可下载。API/发布页超时20秒、清单30秒、安装包连接60秒，临时连接失败最多一次重试；不承诺全程60秒内下载完成，socket超时与总时长不同。
- 取消/校验不匹配等保留原有拒绝与清理机制，下载错误显示具体阶段，浏览器备用入口保留。

## 验证范围

离线测试覆盖DeepSeek/第三方请求差异、长度/空正文/非法JSON、错误分类、API限流/超时的可信回退、连接重试和SHA256保护。`scripts/verify_connection_updates_ui.py`用临时数据和mock验证测试错误提示、同版本回退仍启用下载、进度/成功/校验失败。真实最小调用仅证明当时该Key/模型可用，不等于live分类/问答准确率评测。
