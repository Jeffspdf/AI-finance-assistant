# v0.10.0-rc.2：测试反馈修复

本轮仅处理用户提供的《测试报告_v0.10.0-rc.1.docx》中有定义的 B-01、B-02、B-03。不修改原报告。B-04 只在结尾被引用，正文没有定义；无法判断是遗漏还是笔误，不虚构第四项缺陷。

## 行为变更

- **B-01**：离线帮助增加“AI 储蓄规划”章，共 12 章。包含入口、输入确认、历史/假设模式、显式切换、A/B/C、工具轨迹、claims、授权、取消、规则回退和不写账本边界。
- **B-02**：重新导入默认保持已删除记录，不再静默恢复。桌面/Web 预览列出匹配的已删除来源及删除原因；“恢复本次预览中的已删除记录”默认不勾选。提交分别报告新增、恢复、重复、保持删除和冲突。
- 显式恢复保留原 ID、写审计，并沿用现有失效钩子使相关对账/退款决定待复核，不自动重确认。恢复授权仅限本次预览中的 ID；预览后新删除的其他记录不能随之恢复。匹配身份但金额等内容有冲突时不覆盖，即使勾选恢复也一样。
- 单笔/整批删除都保持此规则；旧的无逐笔删除原因显示“历史删除（无逐笔原因）”。预览不写账本。服务层原三元返回值保持兼容，额外提供 `deleted_skipped` / `restored` 计数。
- **B-03**：同一应用中的帮助窗口复用，重复打开时抬到前面；关闭后可重新创建。

不新增回收站或删除管理页；不改变退款算法、Agent 工具/提示词或数据库结构。内部基础版本仍为 0.10.0，安装包/标签区分 rc.2，数据库模式仍为 6。

- 实际 Tk 控件 smoke 检查帮助单例/12 章、真实导入预览默认不勾选、提交保持删除、勾选后恢复及源账本字节不变。测试运行在未激活的独立 Windows 桌面，不影响用户桌面。它是控件/映射布局验证，不冒充像素截图验收。
