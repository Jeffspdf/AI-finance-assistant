## TLS 评审的处理

没有用 certifi 替换当前解释器的安全资源：已复现的运行时在 SSLContext 构造函数里**无条件读取相邻文件**，设置 SSL_CERT_FILE 或在后面加载 certifi 不能解决这个先发生的异常，也不应删除该环境的安全策略。

正式 CI 保持官方 CPython 3.12（不依赖该私有资源）；在当前受管理解释器本地打包时，保留其要求的公开资源。新增非空、PEM 证书及实际解析校验，并拒绝私钥。本机文件是 OpenSSL 的 TRUSTED CERTIFICATE，可能包含显式拒绝信任标记；同时支持普通及此格式，使用相同加载器原样解析，不删除或转换信任元数据。所有构建继续执行真实 EXE 的 TLS/UI 自检。R4-02 的“完全取消特殊运行时资源”没有在本地构建实现，不能写成已完成；这是可移植性边界而非关闭证书校验的理由。

发布检查必须同时存在安装包、便携包、来源包和 SHA256SUMS.txt，验证大小与 SHA256；安装包仍未代码签名。模型请求不增加自动重试或代理参数猜测；官方 DeepSeek 参数只用于官方 host。

## 可复现的体验

设置 → 六行对账示例 → 生成候选 → 分别确认两组 → 分别拆分。此入口使用独立合成空间，不往个人账本塞示例。初始消费 120 元；确认后 60 元；拆分后 120 元；10 元退款单列待处理；500 元转账不计消费。

实际使用：设置 → 账户与支付绑定 → 账本导入时选格式/账户 → 预览并确认保存来源 → 跨来源对账 → 查看组内来源 → 确认或拒绝。账本保留全部来源，并显示哪条计入统计。
