# ADR 0004：旧分类发现与快照确认绑定

状态：v0.8.5实施。日期：2026-11-03。补充[ADR 0003](0003-category-domains-and-selected-repairs.md)。复核与证据见[第八轮记录](../ROUND8_RESPONSE.md)。

1. 旧收入/支出错分类不自动规范化，但必须有只读发现入口。检测当前空间未删除的所有来源，包含排重资金腿，不受主页面月份影响；按kind筛选、分页并以ID准确定位原交易。空间切换后不跨库编辑，只读空间不编辑，用户必须明确选择合法分类后保存。原转账冲突的备份后启动修复策略保持。
2. Web手工分类先选kind，行与选项均按其限制，表单/编辑器状态按空间和kind隔离；服务端验证仍为最后写入约束，不通过前端过滤替代它。
3. GUI备份清理绑定选中时的文件身份与元数据，在确认期间变化就要求刷新；删除前重新lstat、检查普通文件/重解析属性、目录与身份。不是对敌对同用户进程的原子隔离方案，保留明确确认和受管路径边界，不自动清理。硬链接unlink只移除选中目录项，不沿别名删除。
4. 可写窗口进入时的候选扫描应说明会写候选/维护失效状态，且不会自动确认。只读刷新与只读窗口仍不扫描、不修复存储状态。

无模式升级，不实现退款净额、真实准确率或新银行格式，安装包签名状态不变。
